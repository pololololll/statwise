About StatWise

A statistical analysis website developed as a final requirement for Advanced Statistics.

ABOUT THE PROJECT

Making statistical analysis easier and more accessible

StatWise is a web-based statistical analysis project developed by Paul John F. Lirio, a BSIT-3B student, as a final requirement for the subject Advanced Statistics (ADVSTAT). The website aims to provide a simple and interactive way to perform statistical calculations using a given sample of data.

Through its built-in tools, users can calculate simple linear regression and perform hypothesis testing. StatWise is designed to help students understand statistical results, practice applying statistical methods, and support their learning through an easy-to-use interface.

Simple Linear Regression

Allows users to input sample data and calculate regression results to examine the relationship between two variables and make predictions.

Hypothesis Testing

Allows users to perform hypothesis tests using sample data, calculate test results, and determine whether to reject or fail to reject the null hypothesis.

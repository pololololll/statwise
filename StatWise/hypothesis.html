Hypothesis Testing

Evaluate a claim about a population using sample data, a significance level, and an appropriate statistical test.

✓
Hypothesis Analysis Interactive calculator
THE BASIC IDEA

Test a claim using evidence

Hypothesis testing uses sample information to evaluate a statement about a population.

H₀ versus H₁
01

Null Hypothesis (H₀)

The initial hypothesis evaluated during the testing procedure.

02

Alternative Hypothesis (H₁)

The hypothesis considered in contrast to the null hypothesis.

03

Significance Level (α)

The selected significance level used to determine the rejection region.

04

Confidence Level

Calculated as 1 − α for the selected significance level.

LEARNING REFERENCE

Hypothesis Testing Procedure

  1. 1
    State the hypotheses

    Identify the null and alternative hypotheses.

  2. 2
    Choose the significance level

    Specify the value of α.

  3. 3
    Select the appropriate test

    Choose the test that fits the problem and available information.

  4. 4
    Calculate the test statistic

    Use the sample information and the selected formula.

  5. 5
    Determine the decision

    Compare the statistic with the critical value.

  6. 6
    State the conclusion

    Explain whether the null hypothesis is rejected.
